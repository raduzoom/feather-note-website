# Feather Note website

The website for Feather Note, a native Mac app for Markdown notes with end-to-end-encrypted sync. Plain HTML and CSS in `site/`, served by Cloudflare Pages with no build step. No JavaScript, no cookies, no analytics and no third-party requests.

Check it before publishing:

```bash
python3 scripts/check_site.py
```

## Related repositories

- `feather-note-mac`: the macOS app (MIT)
- `feather-note-server`: the Feather Cloud sync server (AGPL-3.0)
