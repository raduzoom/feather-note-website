# Pricing: FeatherMark

Updated 2026-11-10. Version 1.0.0 is the first release.

## FeatherMark for Mac
- Price: free
- Account: not needed for writing, search, import or export
- Includes: unlimited notes, Markdown export of the whole library, Evernote and Notion import

## Feather Cloud (sync)
- Price: free during the first release
- Includes: end-to-end-encrypted sync between your Macs, one storage quota per account
- Paid plans: none yet; they will be announced on this site before they start

## Self-hosted sync server
- Price: free, open source (AGPL-3.0)
- Runs on: any machine with Docker
