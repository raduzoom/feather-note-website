A native Mac app

Fast to open, light on memory, and at home on macOS: no web view, no account needed to write.

Markdown you own

Every note is plain Markdown. Export your whole library to a folder of .md files any time, for free.

Bring your notes

Import from Evernote and Notion, notebooks, tags, checklists and attachments included. Nothing is dropped.

Sync, end-to-end encrypted

Feather Cloud keeps your Macs in sync and is free during the first release. It stores only encrypted data it can't read.

Or run your own server

The sync server is open source. Run it with Docker on your own machine and point the app at it.

Nothing lost in a conflict

When two devices change a note at once, Feather keeps both. Nothing is overwritten.
